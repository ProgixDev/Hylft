### Rapport d'employabilité premium (Backend)

- **Intégration France Travail IMT** (stats-offres-demandes-emploi v1) — 4 indicateurs connectés par code ROME :
  - `GET /indicateur/salaire-rome-fap/{typeTerritoire}/{codeTerritoire}` — salaires nationaux (débutant SAL1 / moyen SAL2 / expérimenté SAL3)
  - `POST /indicateur/stat-offres` — statistiques des offres d'emploi par type de contrat (CDI, CDD, intérim, etc.)
  - `POST /indicateur/stat-perspective-employeur` — perspectives de recrutement et tension du marché (filtré sur l'année la plus récente)
  - `POST /indicateur/stat-dynamique-emploi` — dynamique de l'emploi territorial (utilise `codeTypeActivite: "MOYENNE"`)
- **Intégration La Bonne Boîte v2** — recherche d'entreprises qui recrutent par code ROME + géolocalisation :
  - `GET /recherche` — top entreprises avec score de potentiel d'embauche
  - `GET /nombreEntreprise` — nombre total d'entreprises identifiées
- **Endpoint agrégé `GET /ft/premium/rapport/:codeRome`** — récupère les 5 sources en parallèle via `Promise.all`, extrait et structure les données avec des helpers privés (`extractSalaires`, `extractOffres`, `extractPerspectives`, `extractDynamique`, `extractEntreprises`).
- **5 endpoints individuels** ajoutés pour accès granulaire : `/ft/premium/salaires`, `/ft/premium/offres`, `/ft/premium/tension`, `/ft/premium/entreprises`, `/ft/premium/rapport`.

### Évaluation d'adéquation IA (Backend)

- **`POST /ai/evaluate`** — compare le profil utilisateur (diagnostics + portrait) aux exigences ROME du métier via GPT-4o.
- **3 sorties possibles :**
  - `candidaterMaintenant` — profil correspond, peut candidater immédiatement
  - `candidaterEtRenforcer` — peut candidater mais devrait renforcer une compétence (avec élément/raison/durée)
  - `formationNecessaire` — uniquement pour les métiers réglementés (quand accèsEmploi mentionne "obligatoire pour exercer")
- **Contexte métier enrichi** — `buildJobContext()` formate le titre, définition, accèsEmploi, compétences et formacodes pour le prompt GPT.
- **Prompt système strict** — tutoiement, NAYHA ne dit jamais qu'elle ne peut pas candidater, sortie 3 réservée aux professions légalement réglementées.
- **Réponse structurée** — `messagePersonnalise`, `pointsForts[]`, `renforcement?` (élément/raison/durée), `formationObligatoire`.
